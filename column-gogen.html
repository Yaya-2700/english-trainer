単語・文法

語源で覚える英単語：接頭辞・語根・接尾辞の基本と、1つで10語に効く組み合わせ

公開日: 2026-10-10｜文: Yaya

英単語を1語ずつ丸暗記していると、覚える量はいつまでも減りません。でも英語の単語の多くは、意味を持った部品の組み合わせでできています。部品をいくつか知っておくと、新しい単語に出会ったときに意味の見当がつき、覚えるのも忘れにくくなります。この記事では、よく使う部品を一覧にして、使い方と注意点をまとめます。

単語は3つの部品でできている

部品位置役割例
接頭辞（prefix）前意味を足す（否定・方向・回数など）review, disagree
語根（root）まん中単語の中心の意味export, inspect
接尾辞（suffix）後ろ品詞を決めるinformation, comfortable

このうち、覚える価値がいちばん高いのは語根です。1つの語根から10語以上が作られていることも珍しくありません。

よく使う接頭辞

接頭辞意味例
re-再び・元へreview（見直す）、return（戻る）、renew（更新する）
pre-前にpredict（予測する）、prepare（準備する）、preview（下見）
pro-前へprogress（進歩）、promote（昇進させる）、produce（生み出す）
un- / in- / im- / il- / ir-〜でないunable、invisible、impossible、illegal、irregular
dis-否定・離れてdisagree（反対する）、discount（割引）、disappear（消える）
mis-誤ってmisunderstand（誤解する）、mistake（間違い）
ex-外へexport（輸出する）、exit（出口）、exclude（除外する）
in- / im-中へimport（輸入する）、include（含む）、income（収入）
inter-間にinternational（国際的な）、interview（面接）
trans-越えて・移してtransport（輸送する）、translate（翻訳する）、transfer（移す）
sub-下にsubway（地下鉄）、submit（提出する）
co- / com- / con-共にcooperate（協力する）、combine（組み合わせる）、connect（つなぐ）
de-下へ・離れてdecrease（減る）、depart（出発する）

in- が「否定」と「中へ」の2つの意味を持つことに注意してください。invisible（見えない）と include（中に入れる）では役割が違います。

覚える価値が高い語根

語根意味この語根からできる単語
port運ぶexport、import、transport、portable、report
spect見るinspect、respect、spectator、prospect、expect
dict言うpredict、dictionary、contradict、dictate
duc / duct導くproduce、introduce、reduce、conduct
ject投げるproject、reject、inject、object
mit / miss送るsubmit、transmit、permit、mission
struct建てるstructure、construct、instruct、destruction
vis / vid見るvisible、visit、video、revise
scrib / script書くdescribe、subscribe、prescription、script
tain保つcontain、maintain、obtain、retain
cap / cept取るaccept、capture、except、receive
press押すexpress、impress、pressure、compress
fer運ぶtransfer、refer、offer、prefer
tract引くattract、contract、extract、distract

たとえば port（運ぶ）を知っていれば、ex（外へ）＋port で「輸出する」、im（中へ）＋port で「輸入する」、trans（越えて）＋port で「輸送する」、port＋able（できる）で「持ち運べる」と、組み合わせで意味が出てきます。

接尾辞で品詞が分かる

接尾辞は意味よりも品詞を決める役割が大きい部品です。これはTOEIC Part5の品詞問題にそのまま効きます。

品詞接尾辞例
名詞-tion / -sion / -ment / -ness / -ity / -ance / -erinformation、decision、payment、kindness、ability、performance、employer
形容詞-able / -ible / -ive / -ful / -ous / -al / -entreliable、possible、effective、careful、dangerous、financial、efficient
動詞-ize / -ify / -en / -ateorganize、notify、strengthen、participate
副詞-lyquickly、recently、significantly

-er と -ee の組み合わせも覚えておくと便利です。employer（雇う人＝雇用主）と employee（雇われる人＝従業員）、interviewer（面接官）と interviewee（面接を受ける人）。-ee は「〜される人」を表します。

語源で覚えるときの注意点

語源は強力な手がかりですが、万能ではありません。

  • 見た目が同じでも別の部品のことがある：discuss の dis- は「否定」ではありませんし、invaluable は「価値がない」ではなく「非常に価値がある」です
  • 今の意味が語源から離れている単語もある：語源は「意味の見当をつける道具」と考えて、最終的な意味は必ず例文で確認します
  • 語源の暗記が目的になると本末転倒：部品を全部覚えようとするより、実際に出会った単語を分解してみる、くらいの使い方がちょうどいい

日々の学習にどう組み込むか

  1. 新しい単語を見たら、分解できないか試す。たとえば「transmit = trans（越えて）＋ mit（送る）」と一度考えるだけで、記憶のフックが1つ増えます
  2. 同じ語根の単語をまとめて覚える。port を見たら export / import / transport / portable を並べて確認する
  3. 覚えた単語は例文で確認する。意味の見当がついても、使い方（どの前置詞と使うか、可算か不可算か）は例文でしか分かりません。EigoNoteの英単語一覧では2,710語すべてに例文がついています
  4. 忘れかけたタイミングで復習する。語源で覚えた単語も、復習しなければ忘れます。間隔反復の考え方を組み合わせると定着が早くなります

まとめ

  • 英単語は接頭辞・語根・接尾辞の組み合わせでできている
  • いちばん効くのは語根。port、spect、dict、mit などは1つで10語近くに効く
  • 接尾辞は品詞を決める。TOEIC Part5の品詞問題に直結する
  • -er は「する人」、-ee は「される人」
  • 語源は意味の見当をつける道具。最終的な意味と使い方は例文で確認する
